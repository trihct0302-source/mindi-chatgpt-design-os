# Skill — Interaction Testing

## Trigger
Use to test interactive components and end-to-end UI flows.

## Checks
Keyboard-only operation, visible focus, logical focus order, activation, dismissal, validation, error recovery, confirmations, loading/success/error feedback, and touch usability.

## Output
Step-by-step test cases, observed result, expected result, pass/fail, and evidence.

## Constraint
Mark untested states explicitly. Sensitive or destructive actions must have clear intent and appropriate confirmation.
