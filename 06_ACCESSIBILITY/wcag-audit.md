# Skill — WCAG Audit

## Trigger
Use when assessing an interface against a specified WCAG target.

## Checks
Perceivable content, operable controls, understandable labels/instructions, robust semantics, keyboard access, focus visibility/order, contrast, text alternatives, and status feedback.

## Output
Finding, applicable criterion, evidence, severity, affected journey, recommendation, and retest method.

## Constraint
State the WCAG version/level and test coverage. A partial audit is not a conformance certification.
