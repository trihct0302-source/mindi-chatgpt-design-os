# Skill — ARIA Specification

## Trigger
Use when defining accessible names, roles, states, and relationships for custom UI.

## Procedure
Prefer native semantic elements. Add ARIA only where native semantics are insufficient. Specify accessible name, role, state, relationship, keyboard behavior, and live-region behavior where needed.

## Output
Component-level semantic/ARIA specification and implementation notes.

## Constraint
Do not use ARIA to compensate for incorrect interaction design or missing native semantics.
