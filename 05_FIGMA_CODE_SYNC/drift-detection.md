# Skill — Drift Detection

## Trigger
Use for periodic or one-time detection of design/code divergence.

## Drift classes
Token value drift, missing component, variant/state drift, naming drift, layout drift, asset drift, and documented intentional exception.

## Output
Drift register with severity, affected surfaces, source versions, likely cause (if evidenced), and remediation proposal.

## Constraint
Separate observed mismatch from suspected cause. No sync operation without L3 approval.
