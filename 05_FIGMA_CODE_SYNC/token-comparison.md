# Skill — Token Comparison

## Trigger
Use to compare design token definitions with implementation values.

## Procedure
Normalize comparable names and values, preserve original identifiers, compare aliases/modes, and classify differences as equal, missing in design, missing in code, changed, or intentionally divergent.

## Output
Token-by-token comparison with source references, impact, and proposed resolution.

## Constraint
No automatic synchronization or overwriting.
