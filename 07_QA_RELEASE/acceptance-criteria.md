# Skill — Acceptance Criteria

## Trigger
Use to define or validate completion criteria for a design or frontend change.

## Format
Given [context], when [action], then [observable result].

## Coverage
Primary journey, alternate/empty/error states, responsive behavior, accessibility, visual consistency, and non-regression.

## Output
Traceable acceptance-criteria checklist linked to requirements and test evidence.

## Constraint
Do not invent business requirements; mark proposed criteria for owner approval.
