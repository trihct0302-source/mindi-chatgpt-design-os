# Skill — Regression Checklist

## Trigger
Use before accepting a design-system, UI, or frontend change.

## Checks
- Existing primary journeys still work.
- Navigation and CTA destinations remain correct.
- Forms, validation, and confirmations remain correct.
- Responsive layouts remain usable.
- Shared components and tokens remain consistent.
- Loading, empty, success, and error states remain clear.
- Keyboard and accessibility behavior remain intact.
- No unrelated files or features changed.

## Output
Pass/fail/not-tested checklist with evidence and issue references.
