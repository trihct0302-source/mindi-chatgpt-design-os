# Skill — Release Report

## Trigger
Use to summarize a reviewed and verified change set.

## Required sections
1. Objective and scope.
2. Approved change summary.
3. Changed artifacts/files and version/commit/PR references.
4. QA coverage and evidence.
5. Known issues and residual risks.
6. Acceptance status.
7. Approval and release status.
8. Follow-up owner and next action.

## Constraint
A release report does not itself authorize merge, publication, or deployment.
