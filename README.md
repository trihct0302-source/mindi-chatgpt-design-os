# MINDI ChatGPT Design OS

A governed design operating system for coordinating design work across Figma, product design systems, frontend implementation, and quality assurance.

## V1 pilot

- Pilot project: `mindi-landing`
- Scope: documentation, Skills, and Workflows only
- Sources of truth: Figma for design artifacts; GitHub for versioned documentation, skills, workflows, and code references
- Default operating mode: L0–L2 (read, analyze, propose)
- Execution: L3 requires explicit approval

## Governance

Every proposed change follows: **Review → Approve → Execute → Verify → Version**.

This repository is documentation and workflow configuration for V1. It does not authorize edits to product source files, Figma files, or deployment targets.

## Structure

The detailed operating model, approval policy, project context, skills, and workflows are maintained in the numbered directories in this repository.

## Status

V1 foundation. Changes are developed on feature branches and submitted through pull requests for review.
