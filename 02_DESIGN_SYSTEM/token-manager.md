# Skill — Token Manager

## Trigger
Use to inventory, compare, document, or propose changes to design tokens.

## Procedure
- Collect token sources and versions.
- Group tokens by purpose (color, typography, spacing, radius, elevation, motion, breakpoint, etc.) only where supported by source data.
- Record name, value, mode, alias, usage, source, owner, and status.
- Identify duplicates, inconsistent naming, and unmapped values.
- Propose changes with impact and migration notes.

## Output
Token catalogue and comparison report.

## Constraint
No token write or sync without L3 approval. Retain historical values and changelog.
