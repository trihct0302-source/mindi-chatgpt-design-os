# Skill — Component Manager

## Trigger
Use to inventory, specify, compare, or govern reusable UI components.

## Procedure
1. Identify component source and version.
2. Record purpose, anatomy, variants, states, properties, and usage guidance.
3. Map component to design and code references.
4. Identify duplication, missing states, inconsistent behavior, and undocumented variants.
5. Propose reuse or consolidation with impact analysis.

## Output
Component inventory, variant/state matrix, mapping, and governance recommendations.

## Constraint
Do not remove or replace components without explicit approval and migration plan.
