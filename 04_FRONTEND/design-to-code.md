# Skill — Design to Code

## Trigger
Use to translate an approved Figma specification into a frontend implementation plan or code proposal.

## Procedure
- Inspect existing code structure and conventions.
- Map design components and tokens to existing implementation.
- Specify semantic HTML, component boundaries, props, states, and responsive behavior.
- Identify assets and dependencies.
- Draft an affected-file plan and test strategy.
- Request L3 approval before editing files.

## Output
Design-to-code mapping, implementation plan, proposed code, and verification checklist.
