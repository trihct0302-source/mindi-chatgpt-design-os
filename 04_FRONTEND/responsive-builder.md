# Skill — Responsive Builder

## Trigger
Use to specify or implement responsive behavior across supported viewports.

## Procedure
1. Collect supported viewport/breakpoint requirements.
2. Identify fluid versus fixed dimensions.
3. Define layout transitions, navigation behavior, typography scaling, image behavior, and touch interactions.
4. Check overflow and content priority.
5. Produce responsive rules and viewport-specific acceptance criteria.

## Output
Responsive specification and test matrix.

## Constraint
Do not invent supported breakpoints; label proposed values as proposals until approved.
