# Skill — Frontend Testing

## Trigger
Use to plan or run implementation verification.

## Test layers
- Static: lint, type checks, build.
- Unit/component: logic, rendering, variants, and states.
- Integration: routes, forms, data, and component interactions.
- Visual: layout and responsive comparison.
- Accessibility: keyboard, semantics, focus, contrast, and labels.
- Regression: previously accepted journeys and screens.

## Output
Test plan/results with command, environment, pass/fail, evidence, and known gaps.

## Constraint
Never report a test as passed unless it was run and its result observed.
