# Skill — Design Generation

## Trigger
Use when creating a new design direction, wireframe specification, component proposal, or visual-generation brief.

## Procedure
1. Extract objective, audience, content, constraints, and required states.
2. Review available brand and design-system references.
3. Propose information architecture and hierarchy before visual polish.
4. Specify layout, components, typography, color roles, spacing, responsive behavior, and interactions.
5. State assumptions and unresolved decisions.
6. Present a reviewable proposal before any source-file change.

## Output
Design brief, page/frame outline, component list, visual direction, responsive/state notes, and acceptance checklist.

## Constraint
Generation is a proposal until approved. Do not overwrite existing Figma assets.
