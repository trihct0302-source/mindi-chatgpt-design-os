# Skill — Layout Audit

## Trigger
Use to inspect layout structure, responsive behavior, overflow, and content fit.

## Checks
- Grid/column behavior and alignment.
- Container widths, spacing rhythm, and breakpoints.
- Text overflow, clipping, wrapping, and overlap.
- Image aspect ratio and crop behavior.
- Header/footer consistency and page-to-page rhythm.
- Loading, empty, and error layouts where supplied.

## Output
Breakpoint-by-breakpoint findings and a prioritized correction checklist.

## Constraint
State which viewport sizes were actually inspected.
